## ✨ Why GhostGMS?

GhostGMS is a Magisk module that optimizes Google Mobile Services (GMS) for:

- 🔋 Better battery life  
- 🔒 More privacy  
- ⚡ Smoother performance  
- 📱 Stable daily usability  

> GhostGMS focuses on **safe optimization**. The goal is to reduce unnecessary GMS behavior without breaking core Android functionality.

| Module | Best For | Notes |

## ⚙️ Installation

1. Download from [Releases](https://github.com/kaushikieeee/GhostGMS/releases)  
2. Flash in **Magisk**  
3. Pick **Core** or **Legacy** module  
4. Select optimization presets/options  
5. Reboot and let the system settle

---

## 🔋 Battery Behavior After Install

You might see temporary drain for **24–48 hours** while Android re-calibrates background behavior.  
That is expected; battery results usually improve after the settling phase.

---

## 🚫 What It Does *Not* Do

- ❌ Core module does not apply kernel-level modification  
- ❌ Does not remove Google apps outright  
- ❌ Does not intentionally break OTA flow  
- ❌ Does not disable all Google functionality blindly

## 🧠 Quick Tips

- Keep only the tweaks you really need  
- Give it 2–3 days before judging battery impact  
- Check module logs for troubleshooting  
- If unsure, start with **Core** first

---

## ❓ Troubleshooting

<details>
<summary>Google Play Services warning appears in some apps</summary>
Usually safe to ignore if your core services still work.
</details>

<details>
<summary>Push notifications feel delayed</summary>
Re-enable Sync-related options if real-time notifications are important for your usage.
</details>

<details>
<summary>Battery got worse right after install</summary>
Wait through the 24–48 hour adaptation period before making conclusions.
</details>
